# Themes

- `$HOME/.config/themes/profiles` contains authored theme sources.
- `$HOME/.config/themes/generated` contains consumer artifacts; do not edit generated files directly.
- Apply source changes through `$HOME/.config/themes/theme-switch` so the active marker and application payloads remain synchronized.
- Applying a profile also updates OpenCode's TUI theme setting.

Read `theme-switch`, profile manifests, and the current marker for supported themes and active state rather than recording mutable values here.
