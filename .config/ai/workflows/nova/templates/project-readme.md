# NOVA Project

Workflow: NOVA
Workflow version: 1

## Authority

- `product-spec.md`: product intent, roadmap, dependencies, and product decisions
- `features/*/T00-spec.md`: feature contracts and authoritative task state
- `INBOX.md`: unresolved user capture and NOVA-managed deferrals
- `product-changes/`: pending/applied Product Change Requests and Product Handoff Requests

Legacy `.ai/` artifacts are separate and are never mixed into NOVA state.

Run `/nova-project-setup` to audit or reconcile this structure. Run `nova-status` for a zero-token documentation summary.
